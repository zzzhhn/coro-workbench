# Coro 合声

一个围绕**编配与排练**的本地音乐工作台：导入录音或乐谱，编辑总谱，生成阿卡贝拉编配，按声部和小节练习，再导出给团员或其他音乐软件。

> 当前为可运行的开发中 MVP。转谱结果需要校对；不承诺任意歌曲的逐乐器精确还原或专业打谱软件全功能替代。当前 P0 是主旋律节奏碎片化，正在针对真实录音迭代。

## 核心功能

- **音频转谱**：本地 Demucs 分轨、Basic Pitch 基础音符；节拍对齐、主唱/伴唱分离、钢琴起音分析与 Chordino 伴奏和弦。
- **词音节奏**：主唱默认使用 ROSVOT / RWBD 学习演唱边界，再联合整理起止；不把逐帧音高掉帧直接变成碎音。保留声学分段等其他路径作对照。
- **PDF / 图片识谱**：本地 Audiveris，将 PDF、PNG、JPEG、TIFF、WebP、BMP 转为可编辑、可播放的谱面，支持原页对照和取消。
- **乐谱编辑**：音符、和弦、休止、歌词、力度、演奏法、移调、音色、单双谱表、批量整理、逐步输入和撤销/重做。
- **一键阿卡贝拉**：SATB / SSAA / TTBB，主旋律选择、风格、难度、移调、人声打击，按实际秒数规划换气；原总谱与编配分别保存。
- **排练室**：分声部阅谱、静音/独奏、分小节循环、节拍器、预备拍、慢练、原音频和分轨对照、主唱音高校对。
- **真实导出**：PDF、MusicXML、MIDI、WAV、MP4、ABC，以及可携带原音频/谱页/分轨的 `.coro` 工程。

界面中文优先。字体与采样音色本地加载；音频处理不调用云端推理。

## 快速启动

已配置好环境时：

```bash
npm start
```

打开 <http://127.0.0.1:5173/>。首次安装或换电脑，请看 [安装与迁移](docs/SETUP.md)。

仅开发编辑器和谱面、不启动后端：

```bash
npm ci
npm run dev
```

已验证环境为 macOS Apple Silicon、Node.js 22+、Python 3.11、`uv`、FFmpeg。模型可以在 CPU 上运行；其他平台尚未完整验收。

## 第一次体验

1. 默认打开原创示例 **Blue Hour / 薄暮**，先检查播放与分声部混音。示例不会冒充转谱结果。
2. 导入自己的音频、MIDI、MusicXML/MXL 或 PDF/谱页图片。
3. 在编配工作台校正节奏与音高，再生成一份阿卡贝拉版本。
4. 在排练室选声部和循环小节；原音频与谱音是不同试听来源。
5. 导出排练谱或 `.coro` 便携工程。普通 `.coro.json` 仅含编辑数据，不包含录音。

已有分析结果在「工程库 → 本机转谱结果」。每次分析单独保存，不覆盖旧谱或手工修改。

## 当前质量状态

最近一轮主唱升级不再只对连续 F0 做切段，而是增加学习到的词/音符边界、实际声音起止对齐和联合节奏成谱。四首本地完整录音中，相比原声学分段，三十二分音符及更短事件分别从 161/199/193/176 减至 27/33/30/61；新模型的有音高事件全部进入谱面，没有用统一删除短音获得这组结果，速度也没有为此翻倍。起止对齐会保留更多确有短时值的音，不以最少符号数量作为唯一目标。

**碎片化减少不是准确率。** 原生 ROSVOT 存在起点偏早；新增声学对齐不统一延后整首，而是逐处寻找进入音高、同音再起和收音。另32段人审清唱回归中，起音+音高 micro F1 对两位标注者分别从25.46%/27.62%提高到55.06%/57.44%；仍有错误和个别退化，不能当作四首混音的准确率。旧分段路径仍可选，缺失引擎会明确回退。[已知限制](docs/LIMITATIONS.md) 记录具体边界。

## 数据与发布

公开仓库只包含代码、测试、安装脚本与可分发的播放素材。**用户歌曲、谱页、转写结果、截图、模型权重和本机研究报告不上传。** 克隆代码不会复制原电脑中的工程；重要作品请私下迁移 `.coro` 文件。

后端仅监听本机，没有面向公网的用户认证与数据隔离，不要直接暴露到公网。请确认自己有处理、改编、演出相关音乐的权利。
