# PDF text font

Noto Sans SC from the Google Fonts / Noto CJK project. The accompanying upstream
license names Adobe (2014-2021) and the reserved font name "Source"; the font is
distributed under the SIL Open Font License 1.1. See the unmodified license file.

The regular TTF is a static weight-400 instance of Google's public variable font:
https://github.com/google/fonts/tree/main/ofl/notosanssc

It is bundled locally only for PDF export so Chinese titles, lyrics and part names
remain legible without an Internet font fetch. The browser PDF engine subsets used
glyphs into the PDF. OFL-NotoSansSC.txt is retained unchanged.

Musical notation paths are generated by abcjs; toolbar glyphs use Bravura under OFL
through the @vexflow-fonts/bravura package. Other UI fonts are loaded locally from
@fontsource, not external font servers.
