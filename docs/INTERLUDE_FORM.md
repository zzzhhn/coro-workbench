# 间奏曲式取舍 · 2026-11-17

## 问题与本轮边界

Bobby 的新反馈是间奏太长、沿用器乐段节奏后听感奇怪。上一轮只处理和声骨架与 SATB 配音，
没有独立决定器乐段应保留多久。逐和弦正确不能推出整段叙事成立。

本轮先验证一个变量：压缩间奏长度。保留部分的音高、时值、配音和速度不重写；不会用
加速播放或额外塞入背景旋律来遮掩问题。源谱小节与改编小节必须分别标识。
这是可逆的候选流程，尚未接入默认 `arrangeV2`，不能称作整曲音乐验收。

## 调研证据

1. **正文全文已读**：Liz Garnett，2022，
   [A Cappella Arranging and Narrative Shape](https://mail.helpingyouharmonise.com/shortstory)。
   她认为有限的人声音色与以歌词叙事为主的聆听方式，可能使照搬录音中的前奏、间奏、重复段
   显得冗长；删减应服务叙事。不是所有阿卡贝拉都必须更短，尤其不能把这条意见当成统一小节数。
2. **公开试读片段已读，并非全书**：Deke Sharon / Dylan Bell，2024，
   [A Cappella Arranging 2.0](https://api.pageplace.de/preview/DT0400.9798216331599_A63012936/preview-9798216331599_A63012936.pdf)，
   书页 5，Decide on a Form。曲式既可删去冗余，也可围绕主题重新组织。
   本轮选择最小的曲式删减实验，没有据此自动重写主旋律。
3. **教学页相关章节已读**：Erik Fredriksen，
   [Conceptual and Collaborative Arranging](https://www.erikfredriksen.com/education.html)。
   先描述歌曲结构和各段情绪，再写具体声部，避免先写下的局部音型绑架整体方向。
   链接中的外部完整编配、讲义和课件未读，不作为本轮证据。

以上是创作原则，不是四小节间奏的标准答案。下面的预算、边界代价是本项目的实验性实现，
需要 A/B 听感判断；不是文献给出的定量结论。

## Pipeline

```mermaid
flowchart LR
  S[可靠原谱与已认可编配] --> F[曲式取舍：内部长空档与段落任务]
  F --> P[保留／压缩／重写为有主题的过渡]
  P --> C[本轮：压缩候选与原谱小节映射]
  C --> H[保留原谱和声与低音方向]
  H --> V[可唱 SATB 配音、共同音与换气]
  V --> G[保护 Solo 与认可片段，检查切口]
  G --> R[同音色同速度同响度 A/B]
  R --> U[真人判断长度、衔接与主唱回归]
```

本轮为隔离变量，对已有全曲候选应用曲式映射，不重新运行 H/V。未来从头生成时，
先决定保留的源谱区间，再在相同区间边界内完成和声与配音，避免失去来源对应。
“重写为有主题的过渡”是下一类可选实验，当前没有实现，更不能自动套一种固定动机。

## 实现与保护

- `src/lib/arrangementForm.ts`：只提议主唱中间的长空档，不删前奏、尾奏，也不删真实 Solo 音符。
- 默认候选门槛是六个完整主唱空白小节，目标保留四小节；晚弱起所在小节计入回归铺垫。
  这些是显式实验参数。只删偶数个完整小节，至少保留两端各一小节。
- 在可选切口中，优先避开正在保持的音，随后比较背景声部音程与两端保留长度。
  小代价只证明该启发式更偏好它，不证明和声或情绪已正确。没有音色、歌曲名、小节号特判。
- 全部声部、和弦、踏板共享时间映射。跨剪接点的背景音符分开处理，不虚构延音线。
  未裁剪的音符保留精确时值，包括三连音浮点数，避免重新相减引入数值漂移。
- 受保护的 Solo／认可片段不删、不改音高时值，只允许因前面的删段整体移位。
  检查使用源谱坐标和事件内容，不再要求删段后绝对起拍仍不变。
- 原版不覆盖；新版本移除依赖原时间轴的原音频同步、旧分析、OMR 小节队列和旧编配报告。
  来源映射放在单独 manifest 中。正式接入前需让工程格式持久保存该映射，不能丢失出处。

## 本地 A/B 与验收

A 使用 `382b317` 全曲候选及已有音频，认可状态仍只属于之前的三个片段。
B 由通用规则选出原谱第 39～42 小节的删段，保留第 36～38 与 43 小节作为过渡；
保留第 43 小节的 Solo 弱起。70 小节成为 66 小节，65 BPM 不变，缩短约 14.8 秒。
这个具体结果由输入算出，只记录在验收文档里，不硬编码到生成器。

私有入口 `tests/private-interlude-review.html`。先比较包含前后主唱的局部范围，再比较整首。
钢琴和人声采样均可选。原谱小节映射、切口、试听备注可见；采样不等于真人唱词。
原先三个认可片段的全部声部事件按时间映射逐项校验，Solo 的 312 个音符内容逐项不变。

只抽查切口及主唱回归谱面，不逐页截图。自动验证包括数据保护、映射、播放定位、音频长度、
响度和削波检查；Bobby 判断是否更自然、是否失去原曲特征、主唱回归是否顺畅。
若长度改善但仍觉得器乐式节奏奇怪，下轮保持该曲式，单独试验过渡段的和声节奏与呼吸；
不能用本轮结果宣称后续问题已经解决。
