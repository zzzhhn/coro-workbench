## 一、Crescendo 交互地图

### 核心状态模型（A + C）

- **工具态**：选择工具（Esc）、音符工具 1–7、休止工具 ⇧1–7、条形线 B、歌词 L、文本 T、
  圆滑线 S、连音工具。选中音符工具后点谱面放置；右键或换工具退出。（A：`01`；C）
- **当前声部**：语音 1–4（⌘1–4）是全局状态，新音符写入当前声部；⌘5–8 显示/隐藏，
  当前声部不能隐藏或静音。（B：工具箱 1/2/3/4；C：Voices）
- **选中 + 音符菜单**：点选或刚放置的音符旁弹出**径向音符菜单**，扇区编号 1–7 即快捷键，
  ⌥+编号切换到其他圈（时值圈、变音记号圈、装饰圈…），Esc 退出，Enter 重新打开。
  鼠标移开自动消失。（A：`01` `03` `04` `09a`；C）
- **状态栏**显示选中音高（例“音高: B4”）。（A：`03`）
- **一次性提示条**：首次使用某工具时底部黄条讲解（例“请使用 SHIFT + 方向键 移动所选音符”）。（A：`01` `05`）

## 三、第一层的设计取舍

- **时值修改不移动后续音符**：与 Crescendo 实测一致（`09b` `10`），也更安全——OMR 的时值误读
  若自动挤后续音，会把错误传遍整首；改为留空或报警并加入校对队列。
- **↑↓ 是调内音级而非半音**：OMR 最常见的错误是线/间差一格；半音仍可用 ⌥。
- **升降号按字母重施加**：再按一次 `=` 不会再升，♮ 回到本位字母。拼写沿用 Coro 现有规则
  （降号调用降号拼写），不新增 `NoteEvent` 字段，所以不影响 MusicXML / MIDI 往返。
- **每个键盘操作都是一次撤销**；歌词无变化不入撤销栈。
- 键盘编辑只在编配工作台生效，排练室行为不变（既有 e2e 覆盖）。

## 五、第二层：原图对照校对（2026-11-15）

数据契约：`project.source.omrReview` 与 `NoteEvent.sourceRef`（PR #30，接口决定
`work/omr-20261114/review/OMR_REVIEW_INTERFACE_DECISION.md`）。编辑器只读，不改识谱数据。

- **谱面 → 原图**：工具栏“原谱”或 `O` 打开右侧面板。选中音符时放大到该声部所在小节，
  虚线圈标出音符的近似锚点；没有选中时显示整个谱表组。跨页自动翻页。
- **原图 → 谱面**：点原图，优先吸附到 0.6 个谱表高度内最近的音符锚点并选中该音符；
  否则按小节框跳到对应小节。标题或页边返回提示，不猜测。
- **小节号换算**：通过 `sourceRef` 在识谱小节号和 Coro 小节之间换算，弱起或插入小节后
  仍对得上；没有引用时用最近已知小节的偏移。
- **一个队列**：`reviewIssues()` 合并重叠、低置信和 OMR 可疑项（超拍、不满拍、无定位、
  各页声部数不一致、文字层、引擎提示），面板按原因筛选；`[` `]` 在当前筛选内逐项跳转，
  “全部”时跳过 `info`（如已贴附的文字）。小节级可疑项也能逐项前进。
- **措辞**：面板固定说明“框和点是识谱给出的近似位置”，边界为估计时另行说明；
  不显示任何置信度。
- 无 `omrReview` 的旧工程：仍可看整页原图，不报错；非识谱工程不显示入口。

## 六、第二层：范围选择、复制粘贴与声部 1–4（2026-11-15）

Crescendo 实测（A 级，`evidence/crescendo-editor/11-12`）：拖框选中所经谱表的**整小节**；
拷贝后在目标小节粘贴，弹出“仅粘贴 / 在选择后覆盖 / 将所有小节插入”三选一。Coro 独立实现：

- **选择**：在空白谱面拖框（选中所经声部的整小节）、`⇧` 点击（从锚点音符到该音符所在小节，
  跨中间声部）、`⇧←→` 扩缩小节、`⌘A` 全选、`Esc` 取消。范围音符整体着色，顶部范围条显示
  小节、声部、音符数和操作按钮。
- **复制 / 剪切**：`⌘C` `⌘X` 复制起点落在范围内的音符；范围末尾截断时值；剪切只清音符，小节保留。
- **粘贴**：点选目标小节的任一音符后 `⌘V` **覆盖**（替换目标小节，延入的长音在粘贴点截断，
  后续小节不动）；`⌘⇧V` **插入**（所有声部与和弦从粘贴点整体后移，总谱保持对齐）。
  粘贴出的音符是新素材：新 id、`manual`，去掉 `sourceRef` 与置信分；大谱表下方谱表的
  声部 5–8 粘到单谱表时折算为 1–4。剪贴板声部多于下方声部、拍号不同、部分声部带和弦时给出提示，
  不静默丢弃。和弦只在全部声部一起复制粘贴时随行。
- **声部 1–4**：工具栏 ①②③④ 与 `⌥1–4`。有选中音符或范围时把它们移入该声部（音高与节奏不变，
  谱面出现对向符干）；否则设为之后输入的声部。大谱表下方谱表沿用 MusicXML 的 5–8 编号并能往返。
  Crescendo 用 ⌘1–4；Coro 的 ⌘ 数字被浏览器标签页占用，改用 ⌥。
- 每个操作都是一次撤销。
