## 2026-11-16：简单吟唱得到部分认可后的诊断方法

Bobby 认为简单吟唱明显优于复杂背景，但具体指出连音、和声和 S/T 音区问题。
保留这条正向反馈，不把“更简单”误解成自动合格，也不重新堆动机掩盖和声问题。

1. **音都在原谱里，不代表和弦结构保住了。** 四个背景声部若重复低音或延伸音，
   可能遗漏原谱真正承载和声性质的音。此次 17/48 漏 F♯、52 漏 B/F♯ 是本地数据
   证据。新候选只在来源实际存在的音中重选，不能按猜出的和弦名称补不存在的音。
   上层三和弦与低音相对三／七度只是可比较的启发式，转位和模糊音集合仍可能误判。
2. **共同音不等于必须连音。** Solo 换气后弱起进入时，背景可以先释放，再在拍点
   重发音。此次断句从 Solo 休止和弱起推导，不按小节指定删音；它仍需听感验证，
   不能把所有 Solo 换气都当成背景必须休止的普遍法则。
3. **区分和弦内容与配音位置。** 20 的旧版已经覆盖原谱 C/E/G/B，不能为了回应
   “不像印象里的伴奏”就编造识别错误。先保持内容，单独比较配音。52 则确有原谱
   B/F♯ 被省掉，应分别处理。
4. **音域边界与常驻音区分别检查。** 旧两段主歌 T 为 G3 至 B3，S 约 G4 至 C5，
   说明声部可唱不等于音色或体感合适。C 采用较高配音偏好，实测两段 S 为 A4 至 E5、
   T 为 B♭3 至 E4；不是歌手通用的“理想音区”，仍须本人跟唱确认。21 至 28 本轮
   只审计不修改，保护其已认可听感。后续偏好应允许按实际歌手调整，而非固定声部名。

关于音域与 tessitura 的区别，外部证据为[教学材料文字片段](https://music.saconnects.org/wp-content/uploads/App.-13.3a-SUMMARY-OF-VOICE-RANGES-AND-TESSITURA-Full-Score.pdf)：
多数音符停留位置与极限音域不同，舒适度因人而异。本轮数值来自本地谱数据，
不是从该材料推出的统一标准。和声诊断为本地实测；新候选好不好听尚待用户验收。

## 2026-11-16：联合配音后的首次明确正向反馈

对象是 `94f8193` 对应的联合配音候选，Solo+SATB，三个短段落。
Bobby 认为第 21 至 28 小节明显进步、有阿卡贝拉的感觉；第 17、18 小节难听，
第 45 至 52 小节没有合格的小节，和声不和谐且难以听出和弦。
这是用户听感，不是自动评分，也不代表完整作品或正式默认生成器已通过。

### 可以迁移的原则，不能直接当结论套用

1. **声线与垂直配音必须一起成立。** 保留短动机的方向与回应节奏，同时检查
   所有实际持续发声的组合。21 至 28 的正向反馈支持继续这条路线；同一算法
   在 45 至 52 失败，说明联合搜索本身并不保证音乐质量。
2. **低音说明落点，内声部说明和弦性质。** 不能让旧低音拖进不兼容的新和弦，
   也不能把有限声部全部分配给延伸音而漏掉必要的三音。允许有意省略、经过和悬挂，
   不建立“每一瞬间必须完整和弦”的硬规则。
3. **在可靠的和声节奏上发展动机。** 第 21 至 24 小节的和声假设各持续一小节；
   失败段同时出现过密转换和过度合并。第 49、50 小节被合成一个 Gmaj9，
   输入低音却多次转换。需要区分和声支点与经过音，不能把它们平均汇总后猜和弦。
4. **共同音持续，不凭空增加音头。** 真正换和弦时才判断长音是否需要转向；
   标记缺失不等于新和弦。音符清爽不能靠删音或额外休止实现。
5. **正向小节不是可复制模板。** 不把 21 至 28 的和弦、节奏、声部角色硬套给
   其他段落，也不按小节号在通用算法里开例外。保留它作为固定回归试听对象。

### 诊断证据及边界

本地候选中，21 至 28 小节至少三个背景声部同时发声的时间是 27/32 拍，
45 至 52 是 28/32 拍。后者低音缺席更少，因此不能将失败归因于“音符不够”。
按当前和声假设，背景中三音缺失分别为 8/32 与 12.5/32 拍；这是排查线索，
不是合格阈值。错误和弦假设也会使这个统计失去音乐意义。

下一次音符实验应优先检查伴奏和声分段、低音支点及内声部功能，再决定是否需要
调整联合选音代价。保持相同音色、响度和输入，比较失败段及 21 至 28 的退步风险。
不能用新的低音指标代替 Bobby 的听感。

### 本轮隔离音色变量

谱和音符保持 `94f8193` 的结果，不创建新编配候选。背景试听默认钢琴，可以切回
原音色；Solo 原样。三个版本一起切换音色。旧人声采样试听保留，新钢琴试听另存。
试听音色通过播放视图实现，不改写声部身份、工程乐器、音符、MIDI 或 MusicXML。

九首已经读过的参考编配仍全部属于开发资料；它们可以提供分析视角，不能充当
未见留出集或证明泛化。这里没有训练模型，也没有完成新一轮听感验收。

## 2026-11-16：把背景节奏当作乐句合同

局部和声到达、共同音延长和临时换气分别决定时值，会让背景在各小节频繁改变节奏身份。新的安静吟唱候选先在四或更多小节内决定共同脉冲和换气周期，再保留原谱和声落点并分配 SATB。参考学习带来的规则是角色持续、不同层独立变化和有理由的例外，不是保存一套可套用的他曲节奏。

学习路径：先段落功能与编制，再比较连续数小节的背景角色；分离节奏身份、和声变化和低音任务；检查换气、音域及录音叠轨；最后把观察转成带反例的约束，用同条件试听检查。作者教材第一章提供了从整体概念到旋律、低音、背景及排练修订的路径：[Sharon / Bell 公开预览](https://api.pageplace.de/preview/DT0400.9798216331599_A63012936/preview-9798216331599_A63012936.pdf)。只读该章，不宣称全文或已训练模型。

本轮 `phrase-pulse` 的边界：源谱整拍和声决定最慢兼容脉冲；真正离拍的短和声不能被抹掉。共同音规律重唱，因此音符可能更多。源谱休止保留，呼吸与短和声冲突会显式记录。四小节稳定是这次用户目标的策略，不是所有曲风的普遍定律。当前仍可能太机械，必须由实际试听判断，不能以节奏种类下降称为编配质量提升。

参考集的阅读收据和详细内容只留本地。新资料在读内容前划开发/留出，旧的已读资料不重新冒充留出。选页阅读与整谱阅读分开记录；保留的未读谱尚不能算一次成功的泛化评测。输入可靠性、同条件混音和用户接受分别核对。


## 2026-11-16：稳定不等于共同重唱，原谱正确也会在减声部时失真

Bobby 已否决上节逐拍脉冲策略，明确要慢歌长音吟唱；不要再将它描述成他的要求或已学会的编配方法。他确认原谱钢琴＋Solo 正常，问题应从转换阶段追查。

本地复现了两个独立损失：钢琴左手上移的和弦音被当成新低音；五音以上结构被裁成“上方已有三和弦”，却丢掉原谱七音。音符全部来自原谱仍不足以保证功能被保留，八度位置也不应决定留下哪个音级。新候选区分低音与和弦，容量不足时优先源谱三音、七音或挂留音。后续低八度同音的确认保护真实低音换位，避免一条新规则吞掉另一种合法写法。

共同音的连贯是发声行为：同一声部同音继续，换音才移动，源谱休止和换气仍可断开。没有固定重唱时钟。这次只验证候选机制，不能把谱面变长、测试通过或减少音头称为听感成功。低音角色推断及减声部仍有歧义，要保留原谱回放、旧候选和具体省略记录，待用户判断。


## 2026-11-16：钢琴和声正确，不保证持续人声配音正确

Bobby 确认后段原谱钢琴正常，上一轮的 13 至 28 相对进步，但 47 至 48 仍不合格。分清三件事：音级来自哪里、减声部留下什么、哪些音在什么八度被持续突出。钢琴的色彩音可以合法，却不必全部作为四个长唱声部的焦点。对于安静吟唱，先保留源谱三音、七音或挂留骨架，明确记录额外色彩的省略；不能把所有六和弦、九和弦一律删成三和弦。

只按背景各声部的最近距离贪心配音，会让前一个八度决定后面的碰撞。需要把不改动的 Solo 实际停留音纳入，区分短暂转音与稳定发声，再在一段内比较声部走向。避免碰撞也不能靠把背景突然抬高一个八度来刷分。仍保留源音级、音域、可见省略、原谱参照与旧版本，最终听感交由用户。

本轮是上述方法的局部候选，不是已学会整曲编配的证明。钢琴与人声采样切换只隔离音色，不改变编配内容；同响度仍不能代替真人演唱验收。
