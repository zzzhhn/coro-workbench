## 2026-11-16：联合配音后的首次明确正向反馈

对象是 `94f8193` 对应的联合配音候选，Solo+SATB，三个短段落。
Bobby 认为第 21 至 28 小节明显进步、有阿卡贝拉的感觉；第 17、18 小节难听，
第 45 至 52 小节没有合格的小节，和声不和谐且难以听出和弦。
这是用户听感，不是自动评分，也不代表完整作品或正式默认生成器已通过。

### 可以迁移的原则，不能直接当结论套用

1. **声线与垂直配音必须一起成立。** 保留短动机的方向与回应节奏，同时检查
   所有实际持续发声的组合。21 至 28 的正向反馈支持继续这条路线；同一算法
   在 45 至 52 失败，说明联合搜索本身并不保证音乐质量。
2. **低音说明落点，内声部说明和弦性质。** 不能让旧低音拖进不兼容的新和弦，
   也不能把有限声部全部分配给延伸音而漏掉必要的三音。允许有意省略、经过和悬挂，
   不建立“每一瞬间必须完整和弦”的硬规则。
3. **在可靠的和声节奏上发展动机。** 第 21 至 24 小节的和声假设各持续一小节；
   失败段同时出现过密转换和过度合并。第 49、50 小节被合成一个 Gmaj9，
   输入低音却多次转换。需要区分和声支点与经过音，不能把它们平均汇总后猜和弦。
4. **共同音持续，不凭空增加音头。** 真正换和弦时才判断长音是否需要转向；
   标记缺失不等于新和弦。音符清爽不能靠删音或额外休止实现。
5. **正向小节不是可复制模板。** 不把 21 至 28 的和弦、节奏、声部角色硬套给
   其他段落，也不按小节号在通用算法里开例外。保留它作为固定回归试听对象。

### 诊断证据及边界

本地候选中，21 至 28 小节至少三个背景声部同时发声的时间是 27/32 拍，
45 至 52 是 28/32 拍。后者低音缺席更少，因此不能将失败归因于“音符不够”。
按当前和声假设，背景中三音缺失分别为 8/32 与 12.5/32 拍；这是排查线索，
不是合格阈值。错误和弦假设也会使这个统计失去音乐意义。

下一次音符实验应优先检查伴奏和声分段、低音支点及内声部功能，再决定是否需要
调整联合选音代价。保持相同音色、响度和输入，比较失败段及 21 至 28 的退步风险。
不能用新的低音指标代替 Bobby 的听感。

### 本轮隔离音色变量

谱和音符保持 `94f8193` 的结果，不创建新编配候选。背景试听默认钢琴，可以切回
原音色；Solo 原样。三个版本一起切换音色。旧人声采样试听保留，新钢琴试听另存。
试听音色通过播放视图实现，不改写声部身份、工程乐器、音符、MIDI 或 MusicXML。

九首已经读过的参考编配仍全部属于开发资料；它们可以提供分析视角，不能充当
未见留出集或证明泛化。这里没有训练模型，也没有完成新一轮听感验收。
